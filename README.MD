**Обзор**

Набор UI‑тестов для веб‑приложения, реализующий паттерн Page Object Model (POM) и Base Test Class. Тесты проверяют функциональность конструктора бургеров, авторизации и регистрации пользователей.


**Технологии и инструменты**

Java 11 — язык программирования;

JUnit 4 — фреймворк для тестирования;

Selenium WebDriver — автоматизация браузера;

WebDriverManager — управление драйверами браузеров;

Allure — генерация отчётов о тестировании;

Page Object Model (POM) — архитектура тестов;

Parameterized Tests — параметризованные тесты.

**Базовый класс: DriverRulesAndBaseTest**
Абстрактный класс, предоставляющий общую инфраструктуру для всех UI‑тестов:

инициализацию WebDriver (Chrome/Yandex);

конфигурацию браузера с необходимыми аргументами;

установку неявных ожиданий (5 секунд);

максимизацию окна браузера;

открытие стартовой страницы (BASE_URL);

создание экземпляров POM‑классов;

подготовку тестовых данных (создание пользователя через API);

очистку после тестов (удаление пользователя, закрытие браузера);

общую логику навигации (метод openLoginPage()).


**Тесты**
ConstructorTest — параметризованный тест конструктора бургеров:
проверяет навигацию по разделам конструктора (начинки, соусы, булочки);
запускается 3 раза с разными параметрами (BurgerIngredients);
проверяет, что при клике на раздел он становится активным.

LoginTest — параметризованный тест авторизации:
проверяет авторизацию через разные точки входа:
главная страница;
личный кабинет;
страница восстановления пароля;
страница регистрации;
использует тестового пользователя, созданного через API.

RegistrationTest — тест регистрации пользователей:
проверка успешной регистрации с корректными данными;
проверка валидации пароля (минимум 6 символов);
очистка после теста (удаление созданного пользователя).

Настройка и запуск
Предварительные требования
Java 11 или выше;

Maven 3.6+;

Яндекс Браузер или Google Chrome;

доступ к тестируемому веб‑приложению.

Зависимости Maven
Убедитесь, что в pom.xml присутствуют следующие зависимости:

xml

**Настройки браузера
Для Яндекс Браузера автоматически:**
устанавливается путь к исполняемому файлу;
применяются аргументы командной строки:
--remote-allow-origins=*;
--no-sandbox;
--disable-dev-shm-usage;
--disable-gpu.

**Отчётность
Тесты генерируют отчёты Allure, включающие:**
шаги выполнения (@Step);
описания тестов (@Description);
названия тестов (@DisplayName);


**Рекомендации по разработке при добавлении новых тестов:**
Наследуйтесь от DriverRulesAndBaseTest.
Используйте существующие POM‑классы для взаимодействия с UI.
При необходимости параметризации используйте @RunWith(Parameterized.class).
Добавляйте аннотации Allure для улучшения читаемости отчётов.
Убедитесь, что тестовые данные корректно очищаются в @After.

**При отладке:**
проверяйте логи консоли для сообщений о запуске браузера;
убедитесь, что версия браузера совместима с версией драйвера;
при проблемах с Яндекс Браузером проверьте путь к исполняемому файлу.

**Устранение неполадок**
Проблема: тест не запускается для Яндекс Браузера
проверьте, установлен ли Яндекс Браузер;
убедитесь, что путь к исполняемому файлу корректен;
обновите версию YandexDriver через WebDriverManager.

**Проблема: элементы не находятся**
увеличьте неявное ожидание в DriverRulesAndBaseTest;
проверьте локаторы элементов в POM‑классах.

**Проблема: ошибки аутентификации**
убедитесь, что API для создания пользователей доступно;
проверьте корректность генерации тестовых данных.
